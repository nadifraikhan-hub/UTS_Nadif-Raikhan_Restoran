WEBSITE RESTORAN - RASA NUSANTARA
=================================

Isi folder:
- index.html : struktur dan konten website
- style.css  : seluruh desain menggunakan CSS eksternal

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder Website_Restoran_UTS.
3. Klik dua kali index.html atau buka dengan browser.
4. Untuk mengedit, gunakan Visual Studio Code atau editor teks lainnya.

Kesesuaian dengan ketentuan tugas:
- Dibuat dengan HTML dan CSS saja (tanpa JavaScript dan framework CSS).
- Menggunakan semantic HTML: header, nav, main, section, article, form, footer.
- Memiliki header, navigation bar, konten utama, 6 kartu menu, formulir kontak, dan footer.
- Menggunakan CSS eksternal (style.css).
